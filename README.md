## 先说结论：跨境专线一个月大概多少钱

市面上能叫“跨境专线”的产品，价格差异极大，主要是三种完全不同的东西在共用同一个名字：

- **运营商国际专线（MPLS/IEPL大带宽）**：按带宽计费，公开报道的价格普遍在每兆每月200～400元。一条5M专线年费约1万元，如果要跑100M，一年就是几十万的量级。这是传统企业级方案，稳定，但贵。
- **SD-WAN类办公方案**：给外贸团队做办公上网用的，第三方选型文章给出的企业级合理区间大约是每月500～3000元。
- **专线VPS**：把专线能力做成云服务器形态，按流量或独享带宽计费，价格直接掉到每月一两百元起步。Mkcloud就是这个类目里的服务商，2023年11月开始运营，产品覆盖广港、沪港、沪日、沪美等线路。

所以“跨境专线费用”没有标准答案，先分清自己要的是哪一类。个人卖家和中小团队大概率看的是第三类，往下也以它为主线。

## 费用由什么决定：别只盯着Mbps

Mkcloud官方知识库里有一篇专门讲定价的文章，说得很直白：专线的价格由出口方向、共享峰值或独享配置、月流量、CPU/内存/硬盘以及接入方式共同决定，不能只凭一个带宽数字比较性价比。

这里面有几个容易踩坑的点：

- **共享带宽的“200M”是峰值**，不保证持续跑满。适合间歇性访问后台、短时间上传素材这类场景。
- **独享带宽看的是持续速率**，比如5Mbps不限流量的独享款，数字不好看，但长时间传输时反而更稳。
- **计量型套餐按上行+下行双向统计流量**，跑够额度后会暂停，需要买流量重置或者补差价升级。
- **不同出口方向价格不同**。香港最便宜，日本略贵，美国因为距离远，同样的配置要贵出一截。

## 报价之外，这些成本和限制要先算进去

专线的钱不只是套餐价，官方商店的下单页把几条硬性规则写得非常清楚，购买前值得逐条看完：

> 所有产品均为云服务器/独立服务器，需中国身份信息实名。全线产品采用省级白名单措施，开通后仅允许你设置的那个省份的IP连入（后续可以修改）。退款仅支持质量问题，且需要提交具体的延迟、速度数据作为证据；服务开通后不支持更换到其他地域。

拆开来看，这意味着几件事：

- **绑定省份**：人在哪个省用就绑哪个省，异地团队要提前确认每个人的接入地，不能只按公司注册地买。
- **IX款的前置成本**：深港IX、沪日IX虽然月付便宜，但需要一台阿里云、腾讯云等支持范围内的云服务器做入口。前置机本身几十到一百多元/月，加上流量费，实际总成本比标价高。有博主测算过，用火山引擎按量计费的 ECS 做前置，流量包大约437元/T/年，用量大时这笔钱不便宜。
- **双向流量统计**：1TB的月流量按上下行双向计算，实际能跑的业务量要按一半估算。
- **没有默认SLA**：官方明确所有产品默认无SLA保证，对可用性有硬性要求的需要单独询价定制。
- **升级要提工单**：升降级都走工单流程，降级到更低价格套餐时差价不退。

## 怎么选不花冤枉钱

把前面的信息压成一个决策路径：

1. **先定出口方向**。客户和平台在哪里，出口就跟到哪里。客户在美国，买广港便宜是便宜，但你每次操作都要绕一大圈，省下的钱会变成时间成本。
2. **再定计费方式**。每天偶尔登后台、传几张图，共享流量款够用；要长时间批量上传、跑持续任务，直接看独享款，5Mbps起步388元。
3. **按真实用量选流量档**。先记录一周的实际用量再估算月度。双向统计意味着1TB档的实际业务流量大约按500GB规划，宁可第一次买低档再补差价升级，也别一上来买大一档。
4. **华南优先广港，华东优先沪港/沪日IX**。已经在用阿里云或腾讯云的团队，IX款的总成本通常最低。

## 常见问题

**跨境专线一个月最低多少钱？**

如果只要能用，Mkcloud的深港IX共享入门约158元/月（沪日IX年付折算约99元/月，但需要自备云前置）。标准直连线路里，沪港IPLC 1TB档288元/月是最低门槎，广港是358元/月。

**用Mkcloud的优惠码现在还能打折吗？**

过去几轮活动（双旦、618、新春等）出过全场8.8折、独享首月7.8折等优惠码，但官方在每期活动回顾里都明确标注：优惠码仅在活动期内有效，活动结束后不能用历史折后价计算新订单。截至本文写作，官网没有挂着长期有效的公开优惠码，下单时以购物车页面的优惠券信息为准。

**能退款吗？**

仅质量问题支持退款，需要提交具体的延迟、速度数据作为证据，由商家审核判断。开通后不支持更换到其他地域，所以下单前把线路方向想清楚。

**能拿来做什么、不能做什么？**

合规用途指在VPS里向外访问：管理店铺后台、调用授权API、上传素材、客户端测试都可以。出口不接受外部连入，不能当公开网站的服务器、游戏服务端，机场和回国等用途被明确禁止。另外它需要中国实名，海外团队没有国内身份的话用不了。

**比运营商专线便宜这么多，靠谱吗？**

两者不是一个产品形态。运营商专线是独享带宽、有SLA的企业服务，专线的钱主要花在“承诺”上；专线VPS是共享峰值加流量额度，默认无SLA。对店铺运营、直播这类容错率尚可的业务，后者性价比高得多；对金融交易、实时生产链路，该上运营商方案还是得上。

## 最后怎么选

跨境专线的费用弹性很大，从每月一百多到每月几万都有，关键不是找“最便宜”，而是找到和你业务流量、延迟要求匹配的那一档。个人卖家从158～358元的入门档试起，成本不高；团队用量大、需要独享带宽，就直接看独享款或者6TB以上的档位。决定之前记得留一次实测的时间——绑定省份和退款规则都摆在那里，选对方向比选对价格更重要。
